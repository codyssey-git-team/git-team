## PR 규칙 / 코드 리뷰 규칙

### PR 본문 필수 항목
- `Closes #이슈번호` — 어떤 이슈를 처리하는 PR인지
- What — 무엇을 바꿨는지
- Why — 왜 바꿨는지
- How — 어떻게 테스트/검증했는지

### 병합 조건
- 리뷰어 1명 이상 Approve

### 코드 리뷰 규칙
- "LGTM"만 남기는 리뷰 금지. 코드 줄을 지정한 실질 코멘트 1개 이상
- 좋은 코멘트 예시
  - "이 함수에 음수가 들어오면 어떻게 되나요?"
  - "docstring에 반환 타입도 적어주면 좋겠습니다."
  - "빈 리스트일 때 IndexError가 날 것 같습니다."
